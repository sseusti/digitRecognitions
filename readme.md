# MNIST Digit Recognition

Веб-приложение для распознавания рукописных цифр. Пользователь рисует цифру мышью на холсте, а нейросеть, обученная на датасете MNIST, определяет, какая это цифра. Модель работает в браузере через TensorFlow.js, без серверной части.

## Запуск

1. Открыть папку в VS Code
2. Установить расширение **Live Server**
3. Открыть `index.html` через Live Server
4. Нарисовать цифру на чёрном холсте и нажать **Predict**; **Clear** очищает холст

> При открытии `index.html` напрямую как файла модель не загрузится: браузер блокирует загрузку `model.json` без локального сервера.

## Модель

Полносвязная нейросеть (MLP), обучена в Google Colab (`train.ipynb`) и сконвертирована в формат TensorFlow.js.

| Слой | Выход | Параметры |
|---|---|---|
| Flatten | 784 | 0 |
| Dense, ReLU | 128 | 100 480 |
| Dense, Softmax | 10 | 1 290 |
| **Всего** | | **101 770** (~400 КБ) |

**Обучение:** оптимизатор Adam, функция потерь `sparse_categorical_crossentropy`, 20 эпох, batch size 1024, пиксели нормированы в [0, 1].

## Структура

```
.
├── index.html          # интерфейс: холст и кнопки
├── script.js           # рисование, предобработка и предсказание
├── tensorflow/
│   ├── model.json              # архитектура модели (TF.js)
│   └── group1-shard1of1.bin    # веса модели
├── train.ipynb         # обучение модели (Google Colab)
└── requirements.txt    # зависимости для обучения
```

## Технологии

- **TensorFlow / Keras** — обучение модели
- **TensorFlow.js** — инференс в браузере
- **MNIST** — датасет рукописных цифр
- **JavaScript, HTML Canvas** — интерфейс

## Возможные улучшения

- Центрировать и масштабировать рисунок перед предсказанием, как в MNIST
- Заменить MLP на свёрточную сеть (CNN) — на MNIST она даёт около 99 %
- Показывать вероятности для всех 10 цифр
- Добавить поддержку рисования на сенсорных экранах
